# python-dev-journey

Mi ruta de 12 semanas para convertirme en **desarrollador Python junior (backend)**. Aquí voy guardando el código y los ejercicios de cada fase, con commits frecuentes para que se vea el avance real.

## Objetivo

Conseguir mi primer trabajo como desarrollador de software. Estudio Ingeniería en Informática en el IPN (UPIICSA), vengo de redes y seguridad, y ahora me enfoco de lleno en desarrollo backend con Python.

## Proyectos

- **Turno** (proyecto estrella): sistema de reservas para negocios que trabajan con citas, como barberías, consultorios o talleres. Calcula horarios libres sin citas encimadas, tiene una API con FastAPI y PostgreSQL, cuentas con roles, páginas para clientes y dueños con HTMX, pruebas, Docker y CI, y está en línea con un negocio real usándolo.
- **finanzas-cli**: herramienta de terminal para registrar gastos e ingresos, importar el estado de cuenta del banco, categorizar movimientos con reglas de regex y convertir compras en dólares a pesos con una API pública.

Cada uno vive en su propio repo: `turno` y `finanzas-cli`.
