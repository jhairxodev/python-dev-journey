# python-dev-journey

Mi ruta de 12 semanas para convertirme en **desarrollador Python junior (backend)**. Aquí voy guardando el código y los proyectos de cada fase, con commits frecuentes para que se vea el avance real.

## Objetivo

Conseguir mi primer trabajo como desarrollador de software. Estudio Ingeniería en Informática en el IPN (UPIICSA), vengo de redes y seguridad, y quiero enfocarme en backend con Python, con la mira puesta en seguridad de aplicaciones.

## Proyecto final

**VulnTracker API**: una API REST para registrar hallazgos de pruebas de seguridad por proyecto, con roles, autenticación JWT, pruebas, Docker y CI.
